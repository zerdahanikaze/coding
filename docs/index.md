# Smart Sales Forecasting — Demo

This repository contains a smart sales and revenue forecasting system with a Streamlit dashboard.

How to view the app (recommended):

1. Deploy to Streamlit Community Cloud:
   - Go to https://streamlit.io/cloud and link your GitHub account.
   - Choose this repository `zerdahanikaze/coding` and deploy `app.py`.

2. Or run locally:

```bash
D:/coding/.venv/Scripts/Activate.ps1
streamlit run app.py
```

This repo also runs a CI job that executes forecasts and uploads the generated CSVs as workflow artifacts.
